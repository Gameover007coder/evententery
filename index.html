Backend Deployment Guide

Quick instructions to launch in 2 minutes

  1. Open your Google Sheet (or create a new blank one).
  2. Go to Extensions > Apps Script in the menu.
  3. Paste the code from CheckInBackend.gs into Code.gs.
  4. Click Deploy > New deployment.
  5. Select type: Web app, Execute as: Me, Access: Anyone.
  6. Authorize permissions and copy the Web App URL here!
